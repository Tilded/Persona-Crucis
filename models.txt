WORKFLOW: QWEN ACCOUNTANT -> STHENO ACTRESS
-------------------------------------------
1. Start a new character with Qwen (prefer the stable Qwen3-8B Q6_K setup,
   or Qwen2.5-7B Q4_K_M for more VRAM headroom).
2. Spend approximately 15 messages establishing the character and allowing
   continuity facts to accumulate.
3. Inspect soul.dump(). Wait until verified facts are at least 3. Do not count
   invented or unsupported claims.
4. Use GobboNet's model dropdown to switch the main model to
   L3-8B-Stheno-v3.2-Q4_K_M.
5. Continue RP with Stheno. Qwen is the careful fact-extraction model;
   Stheno is the character-performance model.

Embedding remains on 11436. Main generation remains on 11437. Changing the
main model does not mean changing the embedding model.

VRAM / MEMORY RULES
-------------------
- RTX 3060 has 8 GB VRAM. Leave room for KV cache, compute buffers, Windows,
  display use, and other GPU processes.
- 16 GB system RAM is a constraint. Large models spilling into RAM may be slow.
- Context length consumes memory. Lower context before assuming the quant is bad.
- Do not load two large main models onto the GPU simultaneously.
- Nemo 12B Q4 at context 16384: crash risk on this 8 GB setup. Use 8192.
- Embedding settings are fixed: batch 384, ubatch 384, threads 2, GPU layers 0.
- VRAM figures are estimates unless explicitly marked user-observed. Actual use
  depends on llama.cpp build, layer split, KV cache type, context, and processes.
